# Typography

Source: Figma `03 Typography` (`35:4619`).

## Правила

- Использовать только системные text styles
- Не задавать произвольные размеры текста
- Иерархия определяется ролью текста (heading / body / caption)
- Composite-токены (`text-heading-1` и т.п.) — основной API, сырые `--font-size-*` применять только при необходимости

## Composite text styles

Готовые к применению стили: размер + высота строки + вес + межбуквенное расстояние в одном токене.
