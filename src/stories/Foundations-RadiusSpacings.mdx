# Spacing & Radius

Source: Figma `02 Semantic` (`35:3020`).

## Правила

- Использовать только системный шаг
- Не применять случайные значения
- Один и тот же тип расстояния = один и тот же token
- Радиус должен быть согласован с типом контейнера:
  - `interactive` (4px) — мелкие элементы, чекбоксы
  - `surface` (8px) — обычные surface-контейнеры, инпуты
  - `card` (16px) — карточки и кнопки
