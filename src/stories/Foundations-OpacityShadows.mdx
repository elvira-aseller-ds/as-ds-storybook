# Opacity & Shadow

## Правила

- Opacity использовать только для системных состояний (`hover`, `active`, `disabled`, `backdrop`)
- Shadow применять только для layer separation
- Не создавать кастомные тени без нового уровня в системе

## Opacity

Используется в alpha-вариантах text/icon и в состояниях фона. В Figma `02 Semantic` alpha запекается прямо в значение цвета (например, `--color-text-secondary = rgba(0,16,41,0.65)`), поэтому здесь перечислены роли и их процент.

<div style={{ display: "grid", gap: 12, marginBottom: 32 }}>
  {opacity.map((token) => (
    <div
      key={token.name}
      style={{
        display: "grid",
        gridTemplateColumns: "220px 120px 80px",
        gap: 16,
        alignItems: "center",
        paddingBottom: 8,
        borderBottom: "1px solid var(--color-border-subtle)"
      }}
    >
      <div style={{ fontFamily: "ui-monospace, monospace", fontSize: 12, color: "var(--color-text-secondary)" }}>
        {token.name}
      </div>

        style={{
          width: "80px",

        }}
      />

  ))}
</div>
