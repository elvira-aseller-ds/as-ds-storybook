# Colors

Source: Figma `02 Semantic` (`35:3020`) + используемые Primitives из `01 Primitives` (`32:3074`).

## Правила

- Use semantic role, not raw color value
- **Action** — primary actions, links, focus rings
- **Text / Icon** — content roles, с alpha-вариантами для иерархии
- **Background** — слои поверхности: page → surface → elevated
- **Border** — разделители и состояния контролов
- **Status** — success / warning / error
- На каждом swatch слева — light, справа — dark тема
