# Size

Размерные токены для элементов и контейнеров. Source: Figma `01 Primitives` (`32:3074`).

## Использование

- controls (buttons, inputs, selects)
- icons
- cells
- cards
- layout blocks

## Правила

- Размер определяется token scale
- Одинаковые сущности должны иметь одинаковый размер
- Не использовать произвольные width / height без причины
- Button height = control height — semantic Small=22, Middle=32, Large=40
