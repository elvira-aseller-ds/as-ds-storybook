# Typography

Семейство компонентов для всего текстового контента: `Text` / `Link` / `Title` / `Label`. Все построены на antd `Typography.*` (кроме `Label` — собственный span с ASeller text-styles, поскольку у antd нет аналога).

Figma source: [Typography (638:114057)](https://www.figma.com/design/VMTYDDrmUYtsva4gGPVEcg/ASeller-DS-v0.1.0?node-id=638-114057).

### Не используется из AntD

- `Typography.Paragraph` — заменён на `<Text>` с правильным размером.
- `editable`, `copyable`, `ellipsis` props — runtime-функционал, добавим по необходимости.
- `code`, `mark`, `keyboard` — не используются в платформе.

## Рекомендации по использованию

**Title — иерархия страниц**
- `Level=1` — заголовок страницы (один на экран).
- `Level=2` — заголовки крупных секций.
- `Level=3` — карточки, блоки внутри секций.
- `Level=4` / `Level=5` — подзаголовки внутри карточек, заголовки списков.
- `Skeleton=True` — при загрузке (вместо spinner для inline-кейсов).

**Text — параграфы и inline-контент**
- `size=base` (14px) — стандарт для основного текста.
- `size=sm` (13px) — captions, sub-info под основным текстом.
- `size=lg` (16px) — emphasis-параграфы (intro, описания крупного контента).
- `strong=true` — для семантического выделения внутри параграфа.
- `caps=true` — для overline-меток секций (CTA, header bars).

**Link — ссылки в трёх контекстах**
- `type=primary` — обычные ссылки в тексте, навигация.
- `type=default` — inline-actions в таблицах (View, Edit), где синий слишком акцентный.
- `type=danger` — деструктивные действия (Delete, Remove account).
- Размер обычно совпадает с окружающим текстом (`size=base` в параграфе, `size=sm` в footer).

**Label — компактные цветные метки**
- `default` — обычные label-ы для полей формы.
- `secondary` — описания, hint-text.
- `disabled` — неактивные элементы.
- `primary` — выделение интерактивного элемента (например, ссылка-кликабельная label).
- `error` / `warning` / `success` — статусные метки в таблицах, badge-ах.
- `white` + `inverse=true` — для тёмных фонов, баннеров, тостов.
- `strong=true` — для усиления label-а в плотных интерфейсах (header таблицы).

## Чеклист QA

### Шрифт
- [ ] Везде Rubik (не Inter, не системный)
- [ ] Веса: Regular (400) или Medium (500); Bold не используется
- [ ] Буквопрбел: `--letter-spacing-default` (0.13px)

### Размеры
- [ ] Title L1=38, L2=30, L3=24, L4=18, L5=16 (font-size в px)
- [ ] Text sm=13, base=14, lg=16
- [ ] Label sm=13, default=14

### Цвета
- [ ] Все color через токены `--color-text-*` или `--color-status-*`
- [ ] Никаких hex-значений (#001029, rgba(...)) в style/CSS
- [ ] Title — `--color-text-heading`, Text — `--color-text-primary`
- [ ] Link primary — `--color-text-link`, danger — `--color-status-error`
- [ ] Label inverse — фиксированный `#001029` фон (одинаков в light/dark)

### Поведение
- [ ] Link с `disabled` не кликабельна, не имеет underline на hover
- [ ] Skeleton показывает placeholder с `--color-bg-hover` фоном
- [ ] Disabled text имеет цвет `--color-text-disabled` (25% opacity)

### AntD-Ready
- [ ] Имена компонентов в Figma — `Typography/Title`, `Typography/Text`, `Typography/Link`, `Typography/Label`
- [ ] Размеры (Size) единообразны между Text и Label (sm)
- [ ] Type-значения для Link и Label не пересекаются с другими доменами (нет своих `info`, `accent` ролей)
